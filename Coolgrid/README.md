The latest finding is that FleetCharge and OffcutPlan contain concrete bounded allocation mechanisms, while RecycledEvidence, ApartmentFOGO and ClimateOdds demonstrate supplied-field checks or content semantics. None has demonstrated robust incremental practical value over competent baselines. Exploratory stronger heuristics matched the showcased optimisation wins; this does not prove equivalence across all possible cases.

Stakeholder roles were simulated. The reference benchmark did not test five finished applications, this repository's UI, real operational records or human participants. Learning, workload, adoption, psychological placebo effects and climate outcomes remain unverified. The 93 adversarial diagnostics include confirmations of model limitations; they are not a product success rate.

The original assessment was exported from its saved Page and checked against the matching Word document. The later files translate the saved research, debate and validation records into Markdown. Their provenance sections distinguish source findings, proposed tests, executed diagnostics and superseded observations. The source JSON records and Python harnesses are not included in this Markdown-only export.

Material AI use: these analyses, simulated debates, reference mechanisms, challenge harnesses and Markdown conversion were produced with an AI assistant and separate agent instances. Agreement between agents was not treated as validation; evidence and counterexamples governed the recorded rulings.
